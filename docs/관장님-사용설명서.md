# 차 태권도 홈페이지 관리 사용 설명서

컴퓨터나 휴대폰에서 홈페이지의 글과 사진을 직접 수정할 수 있습니다.
코딩을 몰라도 되고, 홈페이지 디자인은 바뀌지 않으니 안심하고 사용하세요.

**관리자 페이지 주소: https://www.chataekwondo.com/admin**
(휴대폰 홈 화면에 추가해 두면 편리합니다)

---

## 1. 처음 시작하기 — 비밀번호 만들기

1. 개발자가 카카오톡 등으로 **비밀번호 설정 링크**를 보내 드립니다.
2. 링크를 열고 새 비밀번호를 두 번 입력한 뒤 **[비밀번호 저장]**을 누릅니다.
   - 10자 이상, 영문과 숫자를 섞어 주세요.
   - 비밀번호는 암호화되어 저장되기 때문에 **개발자도 볼 수 없습니다.** 잘 기억해 두세요.
3. **복구 코드**(예: `ABCDE-FGHJK-LMNPQ-RSTUV`)가 표시됩니다.
   비밀번호를 잊었을 때 필요하니 **종이에 적거나 사진을 찍어** 보관하세요. 지금 한 번만 보여 드립니다.
4. "보관했습니다"를 체크하고 [관리자 화면으로]를 누르면 바로 시작할 수 있습니다.

> 링크는 24시간 동안 한 번만 쓸 수 있습니다. "링크를 사용할 수 없습니다"가 나오면 개발자에게 새 링크를 요청하세요.

## 2. 로그인 · 로그아웃

- 관리자 페이지에서 **아이디 `master`**와 **비밀번호**를 입력하고 [로그인]을 누릅니다.
- **로그인 상태 유지**를 체크하면 30일 동안 비밀번호를 다시 입력하지 않아도 됩니다. *도장 공용 PC에서는 체크하지 마세요.*
- 비밀번호를 5번 틀리면 15분 동안 로그인할 수 없습니다.
- 다 쓰셨으면 오른쪽 위 **[로그아웃]**을 누르세요.

## 3. 비밀번호 변경 · 분실

- **변경**: 왼쪽 메뉴 **⚙️ 계정 설정** → 현재 비밀번호와 새 비밀번호 입력 → [비밀번호 변경]
  - 비밀번호를 바꾸면 **새 복구 코드**가 나옵니다. 새 코드로 바꿔서 보관하세요.
- **분실**: 로그인 화면의 **"비밀번호를 잊으셨나요?"** → 아이디 `master`, **복구 코드**, 새 비밀번호 입력 → [새 비밀번호 저장]
  - 복구 코드도 잃어버렸다면 개발자에게 새 비밀번호 설정 링크를 요청하세요.
- **복구 코드를 잃어버렸을 때**: 계정 설정 → [복구 코드 새로 만들기]
- **다른 기기에서 로그아웃을 안 했을 때**: 계정 설정 → [모든 기기에서 로그아웃]

## 4. 도장 소식 쓰기 · 수정 · 삭제

### 새 소식 쓰기
1. 왼쪽 메뉴 **📰 도장 소식** → **[✍️ 새 소식 쓰기]**
2. **제목**, **분류**(예: 도장소식, 승급 심사), **날짜**, **요약**(목록에 보이는 2~3줄)을 입력합니다.
3. **대표 사진** → [사진 올리기]로 사진을 고릅니다. 사진은 자동으로 알맞은 크기로 줄어듭니다.
4. **본문**에 글을 씁니다. 위쪽 버튼으로 꾸밀 수 있습니다.
   | 버튼 | 기능 |
   |---|---|
   | 소제목 | 줄을 굵은 소제목으로 |
   | 본문 | 소제목을 일반 글로 되돌리기 |
   | **굵게** | 글자를 드래그한 뒤 누르면 굵게 |
   | • 목록 | 글머리 기호 목록 |
   | 🔗 링크 | 글자를 드래그한 뒤 주소 연결 |
   | 🖼 사진 | 글 중간에 사진 넣기 |
   | ▶ 유튜브 | 유튜브 영상 주소를 넣으면 영상 표시 |
   | ↶ ↷ | 실행 취소 / 다시 실행 |
5. **본문 아래 영역**: 네이버 블로그 주소, 현장 사진 여러 장 (선택)
6. **[글 올리기]** → 1분 안에 홈페이지에 표시됩니다.

> 💡 블로그나 카카오톡에서 글을 복사해 붙여 넣으면 글자만 들어갑니다. 소제목과 굵게는 버튼으로 다시 꾸며 주세요.

### 수정
도장 소식 목록에서 글의 **[수정]** → 내용 변경 → **[저장]**
- 각 칸에는 지금 홈페이지에 보이는 내용이 들어 있습니다.
- [홈페이지에서 보기 ↗]로 실제 화면을 확인할 수 있습니다.
- 잠시 숨기고 싶으면 맨 아래 **"홈페이지에 공개"** 체크를 해제하고 저장하세요.

### 삭제와 복구
- **[삭제]** → 확인을 누르면 **휴지통**으로 옮겨지고 홈페이지에서 바로 사라집니다.
- 실수로 지웠다면 **휴지통** 탭 → **[복구]**
- 휴지통에서 [영구 삭제]하면 완전히 지워집니다.

## 5. 갤러리 사진 관리

1. 왼쪽 메뉴 **📸 갤러리** → 위쪽 탭에서 카테고리를 고릅니다 (전체 / 프랑스 투어 / 방송·시범 / 승급 심사 / 도장 일상).
2. **사진 올리기**: [📤 사진 올리기] → 사진 여러 장 선택 → 사진마다 **캡션** 입력 → [올리기]
   - "전체 탭에도 추가"를 체크하면 "전체" 탭에도 같이 보입니다.
3. **설명 수정**: 사진의 [수정] → 캡션(사진 위 글), 확대 시 설명, "크게 보이기" 선택 → [저장]
4. **순서 바꾸기**: ◀ ▶ 버튼
5. **삭제**: [삭제] → 휴지통으로 이동 (휴지통 탭에서 복구 가능)

> 사진은 JPG, PNG, WEBP만 올릴 수 있습니다. 아이폰 사진이 안 올라가면 휴대폰에서 바로 올려 보세요 (자동으로 JPG로 바뀝니다).

## 6. 페이지 문구 · 사진 수정

왼쪽 메뉴 **📝 페이지 문구·사진** → 수정할 페이지 선택

| 페이지 | 수정할 수 있는 내용 |
|---|---|
| 메인 화면 | 첫 화면 큰 제목과 소개 문구, 특징 3가지, 숫자(지도 경력 등), 프로그램 소개 3가지(사진 포함) |
| 관장님 인사말 | 인사말 본문, 관장님 사진, 약력·해외 활동·수상 경력 |
| 지도자 소개 | 프로필 사진, 이름, 직함, 인용 문구, 소개글, 자격 태그, 경력, 해외 활동 국가, 수상 경력 |
| 교육 철학 | 본문 전체 |
| 도장 소식 페이지 | 위쪽 소개 문구 |

- 수정한 칸은 **노란색**으로 표시됩니다. 맨 아래 **[저장]**을 눌러야 반영됩니다.
- 칸마다 **[↺ 원래대로]**를 누르면 수정하기 전 내용으로 돌아갑니다.
- **"한 줄에 하나씩"** 칸(경력, 국가, 수상 등)은 줄을 추가하면 항목이 늘고, 지우면 줄어듭니다.
  수상 경력은 `🏅 | 서초구청장 표창`처럼 **아이콘 | 내용** 형식으로 씁니다.

## 7. 실수했을 때 — 변경 기록

왼쪽 메뉴 **🕘 변경 기록**에서 최근 수정·삭제 내역을 볼 수 있습니다.
되돌리고 싶은 항목의 **[이 내용으로 되돌리기]**를 누르면 그때 내용으로 돌아갑니다.

## 8. 자주 묻는 질문

**Q. 저장했는데 홈페이지에 안 바뀌어요.**
A. 반영까지 최대 1분 걸립니다. 잠시 후 홈페이지를 새로고침해 주세요.

**Q. "다른 곳에서 먼저 수정되었습니다"라고 나와요.**
A. 다른 기기나 개발자가 같은 내용을 먼저 수정한 경우입니다. 내용이 덮어써지지 않도록 막아 둔 것이니, 입력한 글을 복사해 두고 화면을 새로 불러온 뒤 다시 수정해 주세요.

**Q. 메뉴 구성이나 디자인을 바꾸고 싶어요.**
A. 디자인과 메뉴는 개발자가 관리합니다. 개발자에게 요청해 주세요.

**Q. 휴대폰으로도 되나요?**
A. 네. 왼쪽 위 ☰ 버튼으로 메뉴를 열 수 있습니다.

문의: 개발자에게 연락해 주세요.
